Flag pictures for all 195 countries.
File names are ISO 3166-1 alpha-2 codes (for example ir.webp = Iran).
They were rendered from Google's Noto Color Emoji font, which is licensed under the
SIL Open Font License 1.1 (https://openfontlicense.org). The mapping from country to file
is in src/data/countries/flagFiles.ts.
